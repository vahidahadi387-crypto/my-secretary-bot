# منشی دیجیتال شخصی تلگرام

این پروژه یک ربات خصوصی تلگرام با منوی فارسی است. امکانات فعلی:
- ذخیره و نمایش یادداشت‌ها
- ثبت کارها و علامت‌زدن کار انجام‌شده با `/done شماره`
- یادآوری زمان‌دار
- ذخیره اطلاعات در SQLite

## راه‌اندازی

1. در تلگرام به `@BotFather` پیام بده، دستور `/newbot` را اجرا کن و توکن ربات را بگیر.
2. شناسه عددی تلگرامت را از یک ربات نمایش‌دهنده User ID بگیر.
3. فایل‌های پروژه را روی یک سرویس میزبانی Python یا سرور شخصی قرار بده.
4. متغیرهای محیطی زیر را تنظیم کن:
   - `BOT_TOKEN`: توکن BotFather
   - `OWNER_ID`: شناسه عددی خودت
   - `TIMEZONE`: منطقه زمانی؛ برای ایران `Asia/Tehran` و برای باکو `Asia/Baku`
5. وابستگی‌ها را نصب کن:
   `pip install -r requirements.txt`
6. اجرا:
   `python main.py`

## اجرای ۲۴ ساعته
برای اینکه ربات وقتی گوشی خاموش است هم کار کند، باید برنامه روی یک سرور/میزبانی همیشه‌روشن اجرا شود. سرویس میزبانی باید اجرای دائمی Python و ذخیره‌سازی پایدار فایل `secretary.db` را پشتیبانی کند. اگر سرویس خواب (sleep) داشته باشد، یادآوری‌ها ممکن است به‌موقع ارسال نشوند.

## نکات امنیتی
- توکن ربات را در گروه یا چت عمومی نفرست.
- توکن را برای من یا هیچ فرد دیگری ارسال نکن؛ فقط در بخش متغیرهای محیطی سرویس میزبانی واردش کن.
- ربات فقط به `OWNER_ID` پاسخ مدیریتی می‌دهد.
- اگر توکن لو رفت، از BotFather آن را باطل و توکن تازه بساز.

## محدودیت نسخه اول
این نسخه یادآوری‌ها را در منطقه زمانی انتخاب‌شده ذخیره می‌کند. فایل پایگاه داده باید روی فضای پایدار سرور بماند؛ در غیر این صورت با راه‌اندازی مجدد یا جابه‌جایی سرور ممکن است اطلاعات از دست برود.
